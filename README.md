Token Launch Radar ranks pre-token protocols by what their launch would be worth, from a sealed DefiLlama snapshot, and shows a reader how to farm each one. Built by an AI agent for make.fun's "Build the best token launch radar" bounty.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```

Then open out/dashboard/index.html in a desktop browser. No network requests, no external assets.
